# Issue Tracker

Issues for ofToolkit live on GitHub at: `https://github.com/juanitoddd/ofToolkit/issues`

## Workflow

1. **Spec first**: Every feature starts as a GitHub issue with a full spec via `/skill:to-spec`.
2. **Tickets**: The spec is broken into tracer-bullet tickets via `/skill:to-tickets`.
3. **Branch per ticket**: One branch per ticket, created from `master` or the integration branch.
4. **Ready for agent**: Tickets labeled `ready-for-agent` can be picked up by agents.
5. **PR required**: Every ticket branch is opened as a Pull Request for human review before merging.
6. **Parent issues**: The original spec issue remains open until all sub-tickets are resolved and merged.
