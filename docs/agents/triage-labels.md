# Triage Labels

Five canonical roles for triaging issues:

| Label | Meaning |
|-------|---------|
| `needs-triage` | Issue has not been looked at yet. |
| `ready-for-agent` | Specced and ready for an implementation agent to pick up. |
| `in-progress` | An agent or human is actively working on it. |
| `needs-review` | PR is open and awaiting human review. |
| `wontfix` | Decided not to implement. |

Additional labels used:

- `bug` — Something isn't working
- `enhancement` — New feature or request
- `documentation` — Improvements or additions to documentation
